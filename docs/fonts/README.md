# Fonts

Self-hosted so the website makes no third-party request (it used to load these from Google Fonts).
Files are the latin and latin-ext woff2 subsets Google serves; `fonts.css` carries the `@font-face` rules.

| Family | Weights | Licence |
|---|---|---|
| Bricolage Grotesque (variable, opsz + wght) | 500 to 700 | SIL Open Font License 1.1, https://github.com/ateliertriay/bricolage |
| IBM Plex Sans | 400, 500, 600 | SIL Open Font License 1.1, https://github.com/IBM/plex |
| IBM Plex Mono | 400, 500 | SIL Open Font License 1.1, https://github.com/IBM/plex |

The OFL permits bundling and redistribution with software as long as the fonts are not sold on their own.
